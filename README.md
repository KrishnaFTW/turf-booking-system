# Turf Booking System

A full-stack Turf Booking & Management System developed using React, Spring Boot, and MySQL.

## Features

- Customer Panel
- Admin Panel
- Slot Booking
- Dynamic Pricing
- QR Code Payments
- Booking History
- Admin Dashboard

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Vite

Backend:
- Spring Boot
- Spring Security
- JWT

Database:
- MySQL
